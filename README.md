# Health Data Analyzer

## Overview

Health Data Analyzer is a Python project designed to practice data analysis and visualization using a sample health-related dataset. The project uses Pandas to analyze the data and Matplotlib to create visualizations of relationships between variables.

## Features

The program allows users to:

* Calculate average BMI, sleep duration, exercise duration, and heart rate
* Visualize relationships between sleep and heart rate
* Visualize relationships between exercise and BMI
* Calculate correlations between selected variables
* Select different analyses through an interactive menu

## Technologies

* Python
* Pandas
* Matplotlib
* Git and GitHub

## Dataset

The project uses a small fictional dataset containing variables such as age, BMI, sleep duration, exercise duration, and heart rate. The data is intended for programming and data analysis practice only and does not represent real patient information.

## Installation and Usage

Install the required Python libraries:

```bash
python3 -m pip install pandas matplotlib
```

Run the program using:

```bash
python3 analyzer.py
```

The program will display an interactive menu that allows users to select different analyses and visualizations.
